🌐 Deepak Meena – Portfolio v3.0 (3D)

🚀 A trendy, fully responsive 3D portfolio showcasing my work as a Software Development Engineer — Full-Stack (.NET / Angular / Azure). Built on top of the v2.0 layout, with a WebGL backdrop and scroll-choreographed camera movement replacing the old video background.

✨ Features

🌀 3D Backdrop (Three.js) – A glowing "core" object with orbiting rings and a starfield; the camera flies to a new viewpoint as you scroll into each section

📊 Scroll Progress Bar – Visual progress indicator while scrolling

🎨 Enhanced UI/UX – Glassmorphism panels, smooth animations, modern layouts, and responsive design

💼 Experience Section – Real production work: Azure deployments, managed identity, CI/CD, and event-driven systems

📂 Projects Showcase – Live/GitHub links for cloud-deployed and personal projects

📖 Education & Certifications – Timeline-based academic and certification details

🛠 Skills – Categorized skill chips across languages, backend, frontend, cloud/DevOps, databases, and tools

📄 Resume Download – One-click PDF download of my latest resume

✉️ Contact Form – Integrated form for quick communication

🔗 Social Links – Direct access to LinkedIn, GitHub, Email, and Phone

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+)

3D: Three.js (WebGL), loaded via ES module import map — no build step required

UI/Effects: Font Awesome, Custom Animations, Glassmorphism

Design: Responsive Layout, Grid & Flexbox, Modern Styling

Accessibility: Reduced-motion support, keyboard navigation, WebGL feature detection with a static fallback background for unsupported browsers
